# 2026-11-06 按钮、菜单与提示文案梳理

本轮在 Holabot 风格整理后的界面上，缩短主要操作路径，减少重复入口和冗长提示。

## 操作路径

- 账户、设置、帮助在侧栏底部直接打开；桌面端保留本机 Agent 入口，服务器切换移至导航区域。手机抽屉固定顶栏和底部入口，只有中间列表滚动。
- 每个侧栏只保留一个“新建群组”。Agent 列表明确标注“本群 Agent”。
- 聊天顶栏直接打开任务、共享文件、搜索；点击成员头像直接进入成员与分工。手机将三项功能放在一个可点击的菜单中。
- 成员与任务页面使用统一返回、关闭区域，避免重复标题和关闭按钮；多级返回后焦点回到原来的群标题。
- 消息菜单优先显示复制、引用，撤回放在末尾；输入框添加菜单移除与当前操作无关的提示。
- 选择 Agent 平台直接进入配置。连接管理默认显示已有连接；新连接从“连接个人 Agent”进入，配置时不混入已有连接的任务表单。
- 高频接入方式直接展示，可选参数和少用连接方式收进展开项；首次接入教程与故障诊断分开。

## 文案与状态

中文、英文同步改为直接说明当前状态和下一步。保留删除、撤销授权、一次性恢复码、实际费用、个人上下文以及结果未知时避免重复投递等有用信息。授权、群权限、事件订阅和在线状态仍分别依据实际数据。

成员看板使用已有连接状态判断在线：没有心跳时可显示已连接，但不推断工作活动；明确离线状态优先。

Manus / Cue 的入口明确提示到平台查看回复；导航和查看连接不会触发任务。保存新的服务连接后返回管理页并选中新连接。
