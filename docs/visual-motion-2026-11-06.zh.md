# 2026-11-06 聊天动效与精细视觉

本轮依据用户提供的《X(twitter) 一优秀设计/AI分享-203期》继续改进 AgentCommons。参考的是连续工具提示、可理解的 Agent 工作状态、统一图标及交互反馈。另查看了 [EasyUI 官网](https://easyui.site/) 的组件与动效方向，实际改动保留现有 React 组件结构。

## 主要变化

- 宽屏下任务、文件与搜索改为右侧工作区，聊天仍可使用；较窄窗口及手机使用完整对话框。切换宽窄布局保留同一组件实例，草稿和当前步骤不因布局转换丢失。
- 聊天采用暖色选中项、清晰的作者与时间层级。短回复保持轻量，列表、代码等结构化回复使用精细内容卡。消息菜单靠近对应消息标题。
- 新消息正文、弹层、工具区、菜单项和内容面板有渐入与位移动效；按钮、卡片、会话项和成员头像有悬停与按压反馈；输入框聚焦时出现柔和边框反馈。
- 动效不改变聊天卡片的布局几何；减少动态效果设置下取消动画和过渡。
- 工具提示首次悬停等待 500ms，组内后续提示即时出现，离开 300ms 后恢复首次延迟；支持键盘、Escape、触屏和边缘定位。
- 任务面板加入真实状态分布与完成数量，任务卡显示完整标题、负责人及来源信息，详情时间线只显示实际存在的记录时间。
- 图标统一方形盒与光学中心，修复 3 个路径几何问题；已知但没有官方资源的平台使用中性字母标。手机平台卡的图标、标题、说明独立对齐。
- Muse 的 MCP 地址和复制按钮移至首屏，授权状态随后展示，安全配置保持可用并后置。
- 修复团队视图把 `presence.current_task` 消息序号误当任务 ID 的问题；当前处理消息与任务台账分别展示。
